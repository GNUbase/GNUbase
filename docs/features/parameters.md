# Parameters

Listing, reading and setting a channel's automatable parameters by value or display text (#30).

- **Parameters** are what automation lanes can target and what has a static value: on channels with audio the fader's `volume` (dB, from -144 to the project's `maxVolume`), `pan`, `panLeft` and `panRight` (-1 to 1; see [mixer.md](mixer.md)), and on instrument tracks the parameters of their built-in instrument ([processors.md](processors.md)). Plugin parameters follow with plugin slots (M05). MIDI channels have none: their volume and pan are MIDI controllers (`channel.set` `midiVolume` and `midiPan`).
- `parameter.list` returns a channel's parameters, `parameter.get` one of them, named by the same `target` object `automationLane.add` takes (`{"type": "volume"}`, `{"type": "instrument", "parameter": 1}`). Each comes with its range, default, unit, whether it is stepped, the names of a stepped parameter's values, its static value and its display text.
- `parameter.set` takes a `value` or a `text`, one undo step. Text is the name of one of the parameter's options, or a number optionally followed by the unit, in any case and with any spacing (`"-6 dB"`, `"2.5s"`, `"rms"`). Values beyond the range stop at its ends; stepped parameters round to whole numbers. Display text is the option's name, or the number with two decimals (whole for stepped parameters) and the unit, the same in every locale (`processors::valueToText` and `textToValue`, which the built-in plugins use as well).
- **Values.** The fader's parameters are the channel's `volume`, `pan`, `panLeft` and `panRight`, so `parameter.set` and `channel.set` change the same values and glide over 5 ms. An instrument's values are in the channel's `instrumentParameters`, only those that were set; the others are at their defaults. A channel that gets another instrument starts with none. Playback takes them as the static values of the instrument's automation lanes ([automation.md](automation.md)): the strip sends them as parameter events when they change, and a lane that reads overrides them while it plays.
- **Files.** `instrumentParameters` is saved in GNUbase's entry of the project file, as a list of `{parameter, value}`. Files from before it have none. Values out of the parameter's range, not numbers, or given twice refuse the file; values of parameters the instrument doesn't have, e.g. from a newer build, and of instruments this build doesn't have are left out. DAWproject itself has no built-in instruments, so other applications don't see them.
