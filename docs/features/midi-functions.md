# MIDI functions

Functions that edit MIDI parts as a whole (#133).

- **MIDI functions** (`src/engine/midi/functions.h`, #133) edit parts as a whole: `midi.transpose` (semitones, scale correction from one scale to another, keeping notes in a range), `midi.legato`, `midi.fixLengths`, `midi.fixVelocities`, `midi.pedalToNoteLength`, `midi.deleteOverlaps` (mono and poly), `midi.deleteDoubles`, `midi.deleteControllers`, `midi.deleteContinuousControllers`, `midi.deleteNotes`, `midi.restrictPolyphony`, `midi.thinOut`, `midi.reverse` and `midi.invert`. Each takes `parts` and, where notes matter, the selected `notes` (all of them if left out), since the selection is not in the document. Notes on different MIDI channels are separate voices: they never shorten, delete or limit each other. `midi.merge` copies what starts between two positions (in samples, like the locators) on some tracks into a new part, `midi.dissolve` moves events by channel or pitch into parts on new MIDI tracks routed to the same instrument, and `midi.bounce` combines a track's parts into one. The functions are plain functions on the document; `functioncommands.cpp` registers them through `ProjectModel::addEdit`, so each is one undo step and can be part of a transaction.
- **The MIDI menu** (`resources/ui/project.rml`, `src/app/appmidifunctions.cpp`, reference manual pp. 1118-1131) runs them in the app. As in the reference, they work on what the Edit menu's quantize commands take ([quantize.md](quantize.md)): in an editor, its selected notes, or every note it edits without a selection; from no zone (Lua, MCP, the menu in the project window), an open editor's selected notes first, else the project window's selected MIDI parts. MIDI > Functions: Legato (`midi.functionsLegato`) extends by the user setting `editing.legatoOverlap` (Legato Overlap, in ticks of 480 to a quarter note, negative for a gap); Fixed Lengths sets the editor's length quantize, or the quantize grid when that is linked to it, as in the project window; Fixed Velocity the editor's insert velocity (100 in the project window); Pedals to Note Length, Delete Overlaps (mono) and (poly), Delete Doubles, Delete Controllers, Delete Continuous Controllers, Thin Out Data, Reverse and Mirror (`midi.invert`) run with no settings, and Restrict Polyphony... asks for the voices. Transpose Setup... asks for the semitones, Scale Correction from a current to a new scale and Keep Notes in Range with the highest and lowest note. Merge MIDI in Loop... (MIDI Merge Options: Erase Destination, Include Chase) merges between the locators the MIDI and instrument tracks that play (the soloed ones, else the unmuted ones) onto the first selected MIDI or instrument track, or a new one. Dissolve Part... separates the project window's selected parts by channel or by pitch, with Optimized Display; Bounce MIDI bounces the selected parts of each track, one undo step for several tracks. The dialogs are one document, `resources/ui/midi-function.rml`, whose Lua runs the engine's command and shows its error if it refuses.
- **Not done yet:** muting the original parts on dissolve instead of moving their events (emptied parts are removed), and Dissolve to Lanes; MIDI effects (Include Inserts, Include Sends, Convert VST3) and chase options beyond controllers in merge, and leaving out muted parts; extracting MIDI automation into automation lanes; the Velocity dialog and Delete Notes... in the menu (`midi.deleteNotes` is there); note names in Transpose Setup's range fields.

## Checks

`tests/midifunctions_tests.cpp` has a test for each function. `tests/midifunctions_ui_tests.cpp` drives the menu with `ui::Automation`: MIDI > Functions on the project window's selected parts (Legato with and without an overlap, Fixed Lengths, Fixed Velocity, Reverse and Mirror, each one undo step) and on an editor's selected notes with its length quantize and insert velocity, and the dialogs: Transpose Setup by semitones, with scale correction and with a value the engine refuses, Restrict Polyphony, Dissolve Part by pitch, Merge MIDI in Loop onto a new track and onto the selected one with Erase Destination, and Bounce MIDI.
