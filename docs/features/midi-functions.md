# MIDI functions

Functions that edit MIDI parts as a whole (#133).

- **MIDI functions** (`src/engine/midi/functions.h`, #133) edit parts as a whole: `midi.transpose` (semitones, scale correction from one scale to another, keeping notes in a range), `midi.legato`, `midi.fixLengths`, `midi.fixVelocities`, `midi.pedalToNoteLength`, `midi.deleteOverlaps` (mono and poly), `midi.deleteDoubles`, `midi.deleteControllers`, `midi.deleteContinuousControllers`, `midi.deleteNotes`, `midi.restrictPolyphony`, `midi.thinOut`, `midi.reverse` and `midi.invert`. Each takes `parts` and, where notes matter, the selected `notes` (all of them if left out), since the selection is not in the document. Notes on different MIDI channels are separate voices: they never shorten, delete or limit each other. `midi.merge` copies what starts between two positions (in samples, like the locators) on some tracks into a new part, `midi.dissolve` moves events by channel or pitch into parts on new MIDI tracks routed to the same instrument, and `midi.bounce` combines a track's parts into one. The functions are plain functions on the document; `functioncommands.cpp` registers them through `ProjectModel::addEdit`, so each is one undo step and can be part of a transaction. Not done yet: muting the original parts on dissolve (parts can't be muted yet, so emptied parts are removed), MIDI effects and chase options beyond controllers in merge, extracting MIDI automation into automation lanes and tempo from MIDI (needs tempo editing, #155, #158).
